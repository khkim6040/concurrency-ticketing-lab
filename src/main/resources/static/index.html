대기 중



  stale 노출은 어떤 전략에서도 0이 되지 않는다. phantomStockViews는 판정에 들어가지 않는다. 캐시를 두는 순간 값이 두 벌이 되고, 둘을 맞추는 방식은 창의 크기를 정할 뿐 창을 닫지 못한다.
  
    
    
  • NONE: TTL(60초)이 끝날 때까지 옛값. 실행이 그보다 짧으면 끝까지 stale.
    • 
    
  • TTL_SHORT: 창이 TTL(1초) 이하로 줄지만 닫히지 않는다. 0으로 만드는 TTL은 캐시를 없앤 것과 같다.
    • 
    
  • INVALIDATE_ON_WRITE: 마지막 쓰기의 삭제 뒤에 늦게 온 재적재는 다시 지워지지 않는다. 판매가 조회보다 빨리 끝나면 걸리지 않는다. raceWindowMs를 올려 보라.
    • 
    
  • REDIS_AS_SOT: 두 번째 복사본이 없어 0에 가깝다. 그래도 읽은 값은 보는 순간 이미 과거다. 이때 oversell 전략은 무시된다.
    •
